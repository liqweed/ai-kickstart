Day 1 · about an hour

Setup

Three things: Obsidian, an AI tool that can work in a folder, and a first hello. This page matches harness steps P0.1–P0.5, so you can also just let the AI walk you through it.

1 · Choose your AI path

Pick the path that matches your comfort level. You can start on one and move up later. The vault doesn't care which AI reads it.

💬

A · Chat app

Easiest. Use the Claude or ChatGPT app with a Project. Upload the kit's key files. The AI can't write into your vault, so it gives you text to paste in.

Comfort 1–2

🗂️

B · Desktop agent ★

Recommended. A desktop AI app that can work inside a folder you choose, reading and writing your notes directly. Examples: the Claude desktop app's Cowork mode, or Craft Agents.

Comfort 2–4

⌨️

C · Terminal / coding agent

Most powerful. Claude Code, OpenAI Codex, Gemini CLI or an editor-based agent, run from the vault folder. Best for scripts and automations later on.

Comfort 4–5

AI tools change monthly Names and features above are a snapshot from autumn 2026. If something doesn't match, ask your AI: "What's the current best way for <your tool> to read and write files in a local folder on <your OS>?". A paid plan is strongly recommended for paths B and C.

2 · Install Obsidian and open the vault

  1. Download Obsidian from obsidian.md/download and drag it to Applications.
  2. Unzip the kit. Move the vault folder somewhere permanent and rename it, e.g. Documents/My Vault.
    Want it on your iPhone too, without paying for sync? Put it in iCloud Drive/Obsidian/My Vault instead.
  3. Open Obsidian → Open folder as vault → choose that folder → Trust author and enable plugins if asked (there are none yet).
  1. Download the installer from obsidian.md/download and run it.
  2. Unzip the kit (right-click → Extract All). Move the vault folder somewhere permanent and rename it, e.g. Documents\My Vault.
    If your Documents folder is synced by OneDrive, right-click the vault folder → Always keep on this device, so the AI never meets "online-only" files.
  3. Open Obsidian → Open folder as vault → choose that folder.
  1. Install from obsidian.md/download (AppImage, .deb, Flatpak or Snap).
  2. Unzip the kit and move vault to e.g. ~/Documents/my-vault.
  3. Open Obsidian → Open folder as vault → choose that folder.

Set up the vault on a computer first. Then, to see it on your phone:

  • Obsidian Sync (paid): simplest and works on every platform. Turn it on in Settings → Sync on both devices.
  • iCloud (iPhone + Mac): free. Keep the vault in iCloud Drive/Obsidian/ and open it from the iOS app.
  • Other (Android/Windows): free options exist (e.g. Syncthing, or a cloud folder plus a sync plugin). Ask your AI to compare them for your devices.

The phone is great for reading briefings and capturing quick notes into _inbox/. The AI work itself happens on the computer.

Four settings worth changing (all platforms)

WhereSettingWhy
Settings → Files and linksAutomatically update internal links: onMoving or renaming a note won't break links.
Settings → Files and linksDefault location for new notes: _inboxQuick notes land in the inbox and get sorted weekly.

Optional, for paths B and C: recent Obsidian versions (installer 1.12.7+) include a command-line interface (Settings → General → Command line interface). It lets an agent move notes without breaking links. It isn't required.

Also optional, for paths B and C: the kit's helper tools (a vault health check, "what's due", a password scan) need Python 3.9 or newer. You don't need to install it now. Harness step P0.6 checks it with you later, and every skill works without it.

3 · Connect your AI to the vault

  1. In your desktop AI app, start a new task/workspace and choose your vault folder as the folder it may work in. Give it only that folder, not your whole Documents.
  2. If the app has a "project instructions" field, paste: "Read AGENTS.md in this folder at the start of every session and follow it."
  3. Run the first-contact prompt below.
  1. Open a terminal in the vault folder and start your agent there (e.g. claude or codex).
  2. Claude Code reads CLAUDE.md, which simply imports AGENTS.md. Codex and most other agents read AGENTS.md directly. Nothing to configure.
  3. Optional: if your agent supports a native skills folder, link it to the kit's skills so they're discovered automatically. For Claude Code on macOS/Linux: 
    mkdir -p .claude && ln -s ../_system/skills .claude/skills
    Not needed: AGENTS.md already tells the agent where skills live.
  4. Run the first-contact prompt below.
  1. Create a Project in your chat app (Claude or ChatGPT).
  2. Upload these files from the vault: AGENTS.md, _system/HARNESS-PLAN.md, everything in _system/kickstart/, and _system/skills/kickstart-interview/SKILL.md + harness/SKILL.md.
  3. Paste the chat-only project instructions below into the project's instructions.
  4. Whenever the AI gives you a block titled with a file path, paste it into that note in Obsidian, then re-upload changed files now and then. More copy-paste, but it works.
Chat-only project instructions
You are my AI setup coach. The attached files are my "AI Kickstart" kit and the current state of my Obsidian vault.
Follow AGENTS.md as if you were working inside my vault, but you cannot write files. Whenever you would create or edit a note, give me a paste-ready markdown block headed with the exact file path instead.
At the start of a conversation, check the attached HARNESS-PLAN.md and tell me in two lines where I am and what's next.

5 · Privacy & safety

The short version Your notes live on your computer. When you ask the AI something, it reads the notes it needs, and those are sent to your AI provider to produce the answer. So: put in what you'd be comfortable with your AI provider processing, and nothing more.
  • Never in the vault: passwords, PINs, full card or account numbers, ID/passport numbers. Use a password manager for those.
  • Check your provider's data settings. Most paid plans let you opt out of your data being used for training. Do it.
  • Work material: follow your employer's AI policy. When in doubt, keep confidential work documents out and store only your own notes and learnings.
  • Other people: write about others the way you'd be OK with them reading it. Factual and kind.
  • Give the agent one folder, the vault, not your whole disk.
  • The "ask first" list in _system/profile/PREFERENCES.md (deleting, sending, spending, installing, connecting accounts) is yours to tighten. Review it in step P0.5.
