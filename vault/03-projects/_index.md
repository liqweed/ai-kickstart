# Projects

A project has an end ("renovate the bathroom", "plan the summer trip", "launch the website").

- `active/`: one note, or one folder with notes, per project. Use the *Project Note* template.
- `ideas/`: someday/maybe.
- `archive/`: finished or dropped.

The one-line status of every active project lives in `_system/profile/PROJECTS.md`.
