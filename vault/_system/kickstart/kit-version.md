# Kit version

This vault's kit files (skills, interview, catalogs, contracts, templates, tools) come from **AI Kickstart v1.3**.

When a new release comes out, say *"Update my kit"*. The `kit-update` skill brings in the new files without touching anything you wrote, and this note moves to the new version with the rest of the kit files. Don't edit it by hand.
