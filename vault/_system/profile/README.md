# Your profile — the AI's long-term memory of *you*

Without these files, every AI conversation starts with a stranger. With them, it starts with someone who knows your goals, your situation, and how you like to work.

The structure is adapted from Daniel Miessler's **TELOS** framework, a public method for writing down what you're about so AI can help with it.

| File | Holds | Changes |
|---|---|---|
| `MISSION.md` | What you're about: purpose, principles, what "a good life/year" means | Rarely |
| `GOALS.md` | What you're working toward this year / half-year, by area | Quarterly |
| `PROJECTS.md` | Things in flight, with a one-line status | Weekly |
| `LANDSCAPE.md` | Your situation: household, work context, devices, tools, routines, hobbies | When life changes |
| `PREFERENCES.md` | How you like things done, including how the AI should behave | When something annoys you |
| `BELIEFS.md` | Values and opinions that should shape advice *(optional)* | Rarely |
| `LEARNED.md` | Lessons worth remembering: mistakes, insights, "next time…" | Whenever |

**Rules:**
- The kickstart interview fills these in. You read the result and correct it. **You have the final word.**
- The AI may *suggest* edits but must show you the change before saving.
- Write only what you'd be comfortable having an AI read. No passwords or ID numbers, ever.
- Short beats complete. A half-page that's true is worth more than five pages that are stale.
