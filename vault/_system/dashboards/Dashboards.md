# Dashboards

Live tables that update themselves as your notes change. They're built with **Bases**, a core Obsidian feature (Obsidian 1.9.10 or newer; turn it on in Settings → Core plugins → Bases). Click a column header to sort. Each table has more views: pick one from the menu at its top left.

They read your notes' frontmatter (`type`, `status`, `summary`…), which is one more reason the [[VAULT-CONTRACT|Vault Writing Contract]] asks for it.
