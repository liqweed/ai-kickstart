# Contributing

Thanks for wanting to make the kit better. It's maintained by Ophir Radnitz and shared under [CC BY 4.0](LICENSE).

## The easiest way to help

**Use the kit, then tell us how it went.** Open an issue with the *Feedback after using the kit* template: what helped, where you got stuck, what you wished it did. Real experience beats clever ideas.

## Ideas and changes

- Open an issue with the *Idea* template first, so we can agree it fits before you write it.
- Pull requests are welcome for fixes and small improvements. Run `scripts/check.sh --optional-scrub` before opening one.
- Read [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) for why things are the way they are, and [`AGENTS.md`](AGENTS.md) for the rules (they apply to humans too).

## Ground rules

- **No personal details** about anyone. Examples must be generic.
- **Keep it friendly and plain.** The readers are not necessarily technical.
- **Keep it tool-agnostic and offline-friendly.**
- **Small and finished beats big.**
