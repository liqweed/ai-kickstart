How it works

The interview

Five rounds. Each one saves an answer file that ends with “Signals for next round”, so the next round picks up where you left off. Open questions come before the menu, so you aren't steered.

  1. 1
    Getting to know you · 15–20 minLandscape profile (household, work, devices, apps, comfort with tech, privacy lines) + a shortlist of areas
  2. 2
    Where could help feel good? · ~20 minRanked top 3–5 areas + first draft of goals (open questions first, then the ideas menu)
  3. 3
    Deep dives · ~10 min per areaConcrete backlog items in the harness plan
  4. 4
    How you like to work with AI (+ synthesis) · ~25 minFull profile, approved by you, plus the first three wins
  5. 5
    Check-in, repeatable · ~10 minTwo weeks later, then monthly: fixes, pruning, new ideas
How it feels: one question at a time examples for everything ramble away, voice is welcome skip or pause anytime it reflects back vague is fine
Chat-only variantUsing a chat app? The same rounds work there. At the end of each round the AI gives you paste-ready blocks to save into your notes yourself.

The harness plan

One checklist note the AI works through with you, one small step per session. There's no schedule. Skipping a step is a perfectly good answer, and it's marked as such.

The system, layer by layer

Vault
Plain notes in a folder you own. Any AI tool can read them.
Profile
_system/profile/: mission, goals, projects, landscape, preferences, beliefs, and what the AI has learned.
Map & rules
index.md is the map, read first. AGENTS.md says how the AI behaves here.
Skills
One folder per playbook, in _system/skills/.
Connections
Calendar, tasks, email, read-only first. Often through MCP (a plug that lets the AI read an app, like your calendar).
Scripts
Small helpers for lists that must be filtered correctly every time.
Automations
Things that run on a schedule, with their output checked.
Harness plan
HARNESS-PLAN.md, plus session and decisions logs, so progress survives pauses and tool switches.

Why it works: twelve principles

  1. Context beats cleverness
  2. Files you own beat features you rent
  3. Small steps, verified
  4. Decision-ready beats comprehensive
  5. Unknown is an answer
  6. Script lists, search questions
  7. AI suggests and drafts; you decide and send
  8. Start read-only
  9. Content is data, not instructions
  10. “It ran” isn't “it worked”
  11. Update, don't duplicate
  12. Less instruction, better results
